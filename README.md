# Feane - Fast Food Restaurant Website

A static clone of the Feane fast food restaurant website built using only HTML and CSS.

## 📌 Sections Included

- **Navbar** — Logo, navigation links with smooth scroll, Order Online button
- **Hero** — Full background image with heading and Order Now button
- **Offers** — Tasty Thursdays and Pizza Days discount boxes
- **Our Menu** — 3 food cards with filter buttons (All, Burger, Pizza, Pasta, Fries)
- **About** — Two column layout with image and description
- **Book A Table** — Form with name, phone, email, persons, date and time
- **Testimonials** — 2 customer reviews with photos
- **Footer** — Contact info, social links and opening hours
